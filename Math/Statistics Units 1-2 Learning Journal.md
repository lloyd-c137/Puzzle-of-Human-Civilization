### Learning record — Purpose and applications of stem-and-leaf plots

#### respond

Discussion based on the Khan Academy stem-and-leaf exercises.

A stem-and-leaf plot is used to organize quantitative data by place value. Its functions are to:

- show how values are distributed;
- preserve every individual observation;
- make repeated values easy to see;
- help find the minimum, maximum, median, mode, range, and total;
- show clusters, gaps, and possible outliers.

For test scores, a stem of \(7\) with leaves \(1,4,4,8\) represents \(71,74,74,78\). I can see that the scores are in the 70s and that 74 occurred twice.

Useful applications include comparing basketball scores, finding the range of store inventory, examining ages, or locating the most common test score.

It is a data display used for analysis. It is especially useful when the dataset is not too large and I want to see both the overall pattern and the exact values.

Khan Academy video: “Classifying shapes of distributions.”

- Symmetric: the left and right sides are roughly mirror images.
- Left-skewed: the long tail extends to the left; most values are toward the right.

- A distribution can look somewhat symmetric and still be more precisely described as bimodal if it has two peaks.

Khan Academy video: “Clusters, gaps, peaks & outliers.”

- A **cluster** is a group of data values close together.
- A **gap** is an interval with no or very few data values.
- A **peak** is a high point or interval with more data than nearby intervals.
- An **outlier** is a value far away from the main group of data, unusually high or low.
- Before describing a graph, identify what is being measured and compare each point or bin with the bulk of the data.

A cluster describes where data gathers. A gap describes where data is missing. A peak describes a local high point, not just any bar that is taller than zero. An outlier must be unusually separated from the main group.

The video used these examples:

- Apple shelf life: a cluster from 4 to 6 days and one unusually high value at 10 days, which is an outlier.
- July temperatures: a peak at (22^\circ\text{C}), but no obvious outlier.

- Test scores: the peak was around 16–17 points, while a score around 0–1 was an outlier. The 12–13 interval was not a peak because nearby values were higher.

A peak must be high compared with nearby values, and an outlier must be clearly separated from the main group. A value is not an outlier just because it is the smallest or largest.
